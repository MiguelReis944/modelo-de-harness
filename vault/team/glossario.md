# Glossário

Termos que aparecem em mais de um projeto do harness. Termos específicos de um só projeto
vivem na página dele em [projetos/](projetos/).

- **Harness**: este repositório guarda-chuva; organiza múltiplos projetos independentes
  via git submodules em `workspace/`.
- **Submodule**: referência do harness a um commit específico de outro repositório Git,
  mantido e versionado independentemente.
